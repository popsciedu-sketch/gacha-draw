# Gacha draw v3 — design notes

**Screen question:** Who is in this draw, at what chance, and who wins?

**Style:** `accent-ladder` (seed 1646467883) · kind community · light

**Face:** Raspberry ladder from the dealt hue — full `#b8336a` only on the primary Draw button, focus rings, and the live weight mark; pale tints (`--accent-soft`, `--accent-track`) fill selected rows and slider tracks. Ground nudged to `#fbf7f8` so page and tints read as one family.

**Idea:** On this screen, each person's chance multiplier becomes a raspberry accent ladder of weight ticks — the weight column is the signature object, not a neon gacha machine.

**Signature element:** Weight ladder column (1–10) next to each participant name; selected participants sit on `--accent-soft`.

**Jobs:** set draw count → select people → tune weights → draw → see winners without duplicates.
